找回你的內網網站

在你的 Wi-Fi 裡測試常見網址，僅列出瀏覽器探測成功的 Web 服務。此頁不使用外部程式庫，也不會把掃描結果上傳。

iPhone／Safari 限制：這是實驗性「瀏覽器探測」，不是完整 Port Scanner。GitHub Pages 使用 HTTPS，可能阻擋存取家中 HTTP 服務；HTTPS 憑證錯誤、區域網路權限也會造成漏報。掃描為 0 不代表家裡沒有網站。
新功能｜Safari 內網模式（推薦先測）

目前的 GitHub HTTPS 網頁，可能被 Safari 阻止連接內網 HTTP 網站。新版可把掃描器存成 Safari 書籤，然後從你確定能開啟的 HTTP 內網網頁 執行，不需安裝 App，也不需電腦。

需要先連網開啟此工具並完成複製，之後在純內網即可使用已儲存的書籤。
  1. 在 Safari 將本頁加入書籤。
  2. 開啟 Safari「書籤 → 編輯」，把剛建立書籤的「網址」全部替換成剛才複製的內容（開頭應為 javascript:）。
  3. 連上內網 Wi-Fi，關閉行動數據；在 Safari 開啟能正常使用的 http://192.168.5.80/booksB1/。
  4. 從 Safari 書籤選單點選剛建立的「LAN Finder 內網模式」書籤，先按「測試目前網址」校正，再開始掃描。
這是實驗性探測：若原站 CSP 限制書籤腳本，或 Safari 仍阻擋跨 IP 請求，可能無法掃描；失敗不能視為 Port 關閉。

掃描不到？先做單一網址診斷

輸入一個你知道能在 Safari 打開的內網網址（例如家中路由器）。「手動能開，但網頁探測失敗」通常代表瀏覽器限制，而不是服務不存在。

只掃描你擁有或已獲得許可的私人網路。此網頁無法辨識自訂 DNS 名稱，也無法直接讀取其他網站的內容。想要可靠的 iPhone 網段與 Port 掃描，仍需使用 Fing 等原生 App。
