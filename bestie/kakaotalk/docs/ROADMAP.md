## 代理分工及交付

開發代理：寫方案、程式、永久測試；開測試分支；提交候選 SHA。獨立 QA（Work）：固定候選 SHA，真實依賴及授權資料隔離驗證，不修改正式程式或 main；報告可重現的缺陷及限制。擁有者決定方案與正式合併／發布。需要 Mac 實機及權限時由擁有者操作或明確授權，不假裝可遠端存取。

每個階段更新 README 和此表，研究結果追加於 RESEARCH 或新的實驗報告；已完成 QA 報告不得重寫。版本管理先核對分支與 blob，任何資料變更、程式變更與純文件整理應分開提交。私有資料留在授權工作區。
