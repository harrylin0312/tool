# 靜讀・英文 Quiet Reader English

單頁試讀：https://harrylin0312.github.io/tool/quiet-reader-english/

參考同一儲存庫 quiet-reader 的米色、墨綠配色與簡潔閱讀版面，獨立新增本資料夾。樣本使用使用者提供的 Neuromancer PDF 第 3 頁，僅包含該頁 5 個正文段落，尚未加入全書。

## 使用

- 每個英文單字（包含篇名）可點選，顯示繁體中文詞義、詞性、原形／詞族與詞彙範圍。
- 範圍內與範圍外的字均可查義；173 個不同字詞的解釋已內嵌，不呼叫線上翻譯 API。
- 詞表外單字沿用先前 PDF 樣本的淺灰色標記；人名、地名略過灰色標記，但仍可點選。
- 此頁的詞性衍生、時態變化與專有名詞經人工語境檢視；這是單頁審核資料，並非可直接套用全書的自動分類器。
- 點同一個字、點外部、按 Esc 或 × 關閉解釋；手機使用底部解釋卡。
- 支援日間／夜間、灰色提示切換、字級與行距調整。設定存於目前瀏覽器。

## 本機與擴充

直接開啟 index.html 即可使用；無框架、外部字型或執行期依賴。GitHub Pages 可直接提供本資料夾。

sample-data.json 保存正文與已審閱詞義，template.html 保存閱讀介面。修改後執行 `python3 build.py` 重建單檔 index.html。之後完整版可在此路徑擴充章節資料；尚未加入的頁面不會假裝能查義。
