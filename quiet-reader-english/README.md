# 靜讀・英文 Quiet Reader English

線上樣本：https://harrylin0312.github.io/tool/quiet-reader-english/

直接沿用同儲存庫 `quiet-reader` 的 HTML 閱讀架構、CSS 與閱讀程式，將預載正文改為使用者提供的 Neuromancer 英文 PDF 第 3 頁，新增點字查義與大考級別。此次仍只有 5 個正文段落，尚未加入全書。

## 與原版一致的架構與工具

- 固定頁首：書庫、書名／作者、搜尋、書籤、Aa 設定、沉浸。
- 左側工具：章節目錄、自動捲動、書籤與筆記。
- 正文：章節標記、章名、字數與時間、短橫線、閱讀區。
- 固定頁尾：上一章、進度、下一章；單頁樣本沒有前後章，按鈕停用。
- 沿用排版偏好、四色主題、書籤、筆記、搜尋、TXT/EPUB 匯入與備份工具。
- 英文版使用獨立 IndexedDB，不會覆寫原版書庫或閱讀進度。

## 點字查義與 Level

- 本樣本每個正文英文單字都可點選，顯示繁體中文解釋、詞性及級別。
- 級別逐項依使用者提供的「大考中心詞彙表 Level 1–6.pdf」對照，資料包含來源詞條與 PDF 頁碼。
- 直接收錄者顯示 `Level N`；變化形式或衍生詞顯示 `詞族 Level N`，並註明對應詞，例如 `tuned → tune · Level 3`。
- 不規則變化依文中用法比對，例如 `found → find`，不誤用 found「創立」的級別。
- 複合字顯示組成詞級別，不把組成詞的級別當作整詞的級別。
- 詞表外顯示「未列入 Level 1–6」，不推測不存在的 Level 7；人名與地理稱呼另行註明。
- 詞表外沿用淺灰色標記，可在 Aa 設定切換。
- 詞義與級別預載，不呼叫線上翻譯服務；尚未建立詞義的匯入書籍使用一般閱讀模式。

## 檔案與建置

- `template.html`：與原版共用結構的頁面範本。
- `app.js`：沿用原版閱讀功能，加入單字按鈕與查義彈窗。
- `style.css`：原版閱讀器樣式。
- `english.css`：英文排印與查義彈窗的增補樣式。
- `content.js`：原版 TXT/EPUB 匯入工具。
- `sample-data.json`：5 段英文正文、173 個不同字詞的詞義與級別依據。
- `build.py`：驗證完整詞義覆蓋、級別與來源後，產生含預載資料的 `index.html`。

執行 `python3 build.py` 重建；本機使用 `python3 -m http.server 4178`，再開啟 http://127.0.0.1:4178/。無需 npm 安裝或外部 API。完整版可延續相同資料夾與閱讀器，後續再擴充章節及已審核詞義。

## 驗證範圍

已檢查正文 169 個不同字詞皆有解釋、JavaScript 語法、原版閱讀版面、tuned 的詞族 Level 3、直接收錄級別、詞表外顯示、搜尋與排版設定；並以桌面及 390×844 視窗檢查查義卡。未在實體 iPhone Safari 驗證。
