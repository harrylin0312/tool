# 靜讀 Quiet Reader

GitHub Pages 公開閱讀網址：https://harrylin0312.github.io/tool/quiet-reader/

完整原始碼、文件與測試程式位於本資料夾。`npm test` 會先產生原創 TXT 與 EPUB 測試資料。

以閱讀為主的繁體中文小說閱讀器。無框架、無 CDN、無執行期依賴，所有書籍與狀態均存於瀏覽器 IndexedDB。部署網址的資料與 localhost 的資料彼此獨立，可透過完整備份轉移。

## 啟動

需要 Python 3；測試需要 Node 22 以上。

```sh
cd quiet-reader
npm start
```

開啟 http://127.0.0.1:4173 。也可執行 `python3 -m http.server 4173 --bind 127.0.0.1 --directory dist`。不需要 npm install 或建置。`npm test` 執行內容處理測試。

## 使用

- 滾動閱讀時工具會淡出；輕點正文或右下角圓形符號可叫回工具。鍵盤 F 切換沉浸。
- Aa 開啟即時排版。支援字體、字級、字重、行距、字距、段落間距、寬度、留白、對齊、縮排、四色主題、自訂配色、多組偏好與設定匯出。
- 頁尾進度可開目錄；桌面左側也有目錄。搜尋可跨章節或限目前章節。
- 自動閱讀可由 Aa 或桌面左側開始；2–80 px/s，精度 0.5 px/s。空白鍵暫停／繼續；章末、觸控、滑鼠滾輪、開面板、切到背景時會暫停，切章停止。
- 左右方向鍵逐屏移動；[ ] 切章；B 書籤；Esc 停止自動閱讀並喚回工具。手機逐屏模式支援水平滑動；不會直接滑到另一章。
- 選取文字後，Aa → 書籤與筆記，可保存選取內容與筆記。選取文字仍可使用系統複製。
- 書庫支援 UTF-8 / Big5 TXT 與無 DRM EPUB。EPUB 依 OPF spine 排序，不以 ZIP 或檔名字母排序；只以純文字呈現，匯入內容不會執行 script 或載入圖片。
- 書籍最大 30MB、解壓宣告大小上限 80MB、文字上限 2,000 萬字。過大、加密或無有效章節的檔案會提示。
- 合法本機書籍可離線閱讀。第一次在線載入後 Service Worker 快取應用；瀏覽器清除網站資料會同時移除書庫，請使用書庫的完整備份匯出。

## 九九藏書來源

實際瀏覽來源頁後，Cloudflare 自動驗證正常通過，沒有繞過安全驗證或廣告。目錄是 4 部加終章，共 24 章。原始擷取順序與實際頁面不同；正文中保留干擾節點，且呈現受網站 JavaScript 與可視區域影響。詳細證據見 SOURCE-RESEARCH.md。

本應用沒有附帶《神經漫遊者》全文，也沒有背景批次抓取小說。尚未取得全文保存授權確認。可使用原站正常閱讀與 `dist/source-reader.js` 原頁排版工具；它只加樣式及自動捲動控制，不刪除廣告、不解除隱藏節點、不保存正文、不改變章節導覽。

桌面使用方式：正常開啟原閱讀頁並完成網站流程後，在瀏覽器開發者工具的主控台執行 source-reader.js。也可將整段程式前加 `javascript:` 存成書籤，於閱讀頁點選。網站 CSP 或瀏覽器政策可能限制書籤程式；原頁工具尚未完成實際注入後驗證。手機 Safari 建議先使用 EPUB/TXT 匯入。

## 架構

- `dist/app.js`：閱讀狀態、IndexedDB、段落錨點、即時排版、書庫、搜尋、書籤、捲動與互動。
- `dist/content.js`：獨立 TXT / EPUB 匯入與驗證，便於擴充來源。
- `dist/source-reader.js`：在原網站上執行的暫時排版工具。
- `dist/sw.js`：同來源應用快取；不快取外部小說網站。
- `tests/`：原創長篇及 EPUB 測試資料和自動測試。

## 限制

- 已驗證桌面與 390×844 手機視窗，未在實體 iPhone Safari 驗證；不能宣稱已通過 Safari 相容性或長時間效能測試。
- 原站完整單章未完成逐段至章末的完整性比對，更未驗證 24 章全文；不把網頁原始文字順序當成正確內容。
- 逐屏模式是按一屏捲動，並非橫向分欄電子書分頁；無圖片、註腳超連結與 EPUB 原始 CSS。
- 預估時間以每分鐘 450 字計算，未學習個人閱讀速度。
- 沒有跨裝置同步或帳號。離線快取與防休眠受瀏覽器政策限制。
- 位置保存到段落與段內高度比例；對超長單一段落，跨裝置重排可能只能維持近似位置。
